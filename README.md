# DSAfrm02hero

# 🚀 DSA 0 → Hero

> A structured Data Structures & Algorithms journey from beginner to interview-ready.

## 📌 About

This repository documents my DSA preparation from scratch. Instead of solving problems randomly, I follow a **phase-based roadmap** while using a combination of the **Striver A2Z DSA Sheet** and the **NeetCode 250** roadmap.

The goal is not just to solve problems, but to understand the underlying **patterns**, improve problem-solving skills, and prepare for software engineering interviews.

---

## 🎯 Goals

* Build strong DSA fundamentals
* Learn problem-solving patterns instead of memorizing solutions
* Master C++ STL
* Become interview-ready for internships and placements
* Maintain clean, well-documented solutions

# 📄 Solution Format

Each solution includes:

* ✅ Problem Name
* ✅ Platform
* ✅ Difficulty
* ✅ Pattern Used
* ✅ Time Complexity
* ✅ Space Complexity
* ✅ Clean C++ Solution
* ✅ Key Learnings

Example:

```cpp
// Problem: Two Sum
// Platform: LeetCode
// Difficulty: Easy
// Pattern: Hashing
// Time Complexity: O(n)
// Space Complexity: O(n)
```

* Prioritize consistency over speed.
* Write clean, readable solutions.
* Review and revisit problems regularly.
* Focus on reasoning, not memorization.
